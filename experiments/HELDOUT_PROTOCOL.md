# Независимая от настройки проверка, 10.10.2026

Зафиксировать в Git до подготовки новых кадров и запуска методов.

## Гипотезы

Основная H0: медиана изменения полноты локализации по новым видео при
добавлении текстовой проверки с обученным Махаланобисом не больше нуля.
H1: медиана изменения больше нуля. Успех кадра: IoU >= 0.5 с целевым ID.
Заранее заданное основное сравнение: geometry против text_full.
Односторонний точный знаковый тест, alpha=0.05, единица — видео, нулевые
разности исключаются из биномиального теста и явно считаются. При всех нулях p=1.
Тест предполагает независимые видео и одинаковую вероятность знака при H0;
происхождение клипов может не гарантировать независимость, это ограничение.
Неотвержение H0 не является доказательством равенства или отсутствия пользы.
Практическую полезность нельзя заявлять при увеличении чужих принятий.

## Данные и неизменяемые правила

Восемь ранее не использованных клипов официального GMOT-40 v0.1:
airplane-0..3, boat-0..3. Предыдущие train/validation — только car-0/car-1.
Это перенос на другие виды техники, а не новый автомобильный benchmark.
Архивы и лицензия CC BY-NC-SA 4.0 те же, что в GMOT40_REPRODUCE.md.
Сначала первые 300 кадров каждого клипа (либо все, если короче).
Цель — минимальный числовой ID, имеющий рамку >=40x20 на кадре 0 и минимум
30 размеченных кадров до 300. При отсутствии такого ID клип фиксируется как
непригодный; заменять более удобной сценой нельзя.
Один эталон — GT-вырезка кадра 0; он исключается из оцениваемого видео.
Вход алгоритма не содержит координат цели на видео. Эталон из той же сцены,
не независимая съёмка. Подтверждённые ID/рамки сохраняются в манифесте.
Все кадры 1..299 обрабатываются последовательно, включая неразмеченные по цели.
Отсутствие ID в разметке само по себе не доказывает отсутствие цели: такие
кадры ignore. FPR на отсутствии в этом опыте не оценивается без ручной проверки.
Рамки отвлекающих ID используются только при оценке; полнота их списка неизвестна.

## Методы, параметры и контроли

Одинаковый исправленный SIFT/RANSAC + optical flow, width1920, seed2027,
контроль семантики при захвате и каждые 10 секунд, рабочие fps=30.
G: geometry; I: исходный текстовый изотропный Махаланобис Sigma=0.01I, tau=6;
C: текстовые PCA8/L2-признаки с cosine; M: те же признаки с полной обученной
ковариацией Ledoit–Wolf. Для C и M без изменений переносятся parameters.json
и validation-пороги прошлого опыта: train car-0, validation car-1, K=1.
Для I точный эквивалент косинусного порога равен 0.18, это не отдельное
преимущество метрики. Никакой подстройки на самолётах/судах.
VLM Qwen3.5:0.8b, независимые описания, пустой контекст; SBERT snapshot
1110a243fdf4706b3f48f1d95db1a4f5529b4d41. Текстовые признаки выбраны для
проверки исходного дополнительного семантического модуля, не новой V+T модели.
Кэш описаний общий между тремя семантическими вариантами внутри нового опыта:
совпадающие изображения получают одинаковый текст, предотвращая смешение
эффекта метрики с повторной генерацией. Старые captions не используются.
Порядок вариантов G,I,C,M фиксирован; времена с кэшем не являются честным
сравнением скорости метрик. Количество cache hit и cold вызовов записывается.

## Метрики, ошибки и отчёт

Recall=TP/N_present. Mean IoU — среднее по всем кадрам присутствия, включая
нулевые значения при отказе. Precision=TP/(TP+FP); выданная рамка с IoU<0.5
считается FP и FN на присутствии. Wrong-ID — FP с IoU>=0.5 к иному ID.
Сохраняются потери/повторные захваты, все рамки, описания, решения, полное время.
Основная агрегация — среднее по видео, дополнительно micro по кадрам.
Предусмотрены кривые успешности по IoU от0.1 до0.9 без выбора рабочего порога.
Парный bootstrap по целым видео, seed2027, 10000 повторов: описательные
95% интервалы разностей; при малом числе сцен они не подтверждающие.
Восемь клипов не означают восемь гарантированно независимых источников.
Начальный отказ из-за недостатка SIFT-точек учитывается нулевыми предсказаниями
для всех кадров (операционный отказ), не исключается из средней.
Другие программные сбои сохраняются и не подменяются научным результатом.
Пороги, выбор сцен и алгоритмы после просмотра результатов не меняются.
Подписи графиков — на русском. Отдельное дополнение к отчёту, без стирания
предыдущих результатов; исходные пиксели и веса не включать в Git.
