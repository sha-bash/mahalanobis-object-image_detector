# План сравнения визуальных и текстовых признаков 10 октября 2026

До извлечения новых признаков и подбора параметров фиксируется следующий протокол.
Гипотеза H1: текст дополняет визуальное сопоставление и уменьшает ложные принятия
при recall не ниже 0.70. H2: обученная регуляризованная метрика Махаланобиса
улучшает сравнение относительно косинусного расстояния на одинаковых признаках.

## Выборка и ограничения

Официальный GMOT-40 v0.1, все четыре car-клипа, source frames <300. В каждом
выбираются первые шесть ID по номеру с >=61 размеченными кадрами, где bbox >=40x20.
Из отсортированных пригодных кадров берутся позиции 0,10,20 как референсы и 40,60
как кандидаты. Кандидатные кадры не входят в референсы. Никакого отбора по score.
24 экземпляра, до120 crops. car-3 анализируется отдельно как визуально игровая сцена.
Все исходные кар-клипы уже использовались в пилоте: новый анализ исследовательский,
не объявляется нетронутым подтверждающим тестом. Физическое межклиповое тождество
не установлено; ID всегда составной clip:id. Внутри fold нет пересечения сцен.

Кандидаты — рамки из GT, а не выход детектора. Это контролируемая оценка
распознавания экземпляра, не новой полной системы поиска или сопровождения.
Для каждого из шести query оцениваются все12 кандидатов своей сцены: два positive,
десять negative. Один либо три reference; оба протокола отдельно. Предсказанное
сходство — минимум расстояния до доступных референсов (для SIFT максимум score).
Оценка top1 отвечает на вопрос выбора цели среди12 кандидатов и всегда допускает
два правильных кандидата; не смешивается с пороговой pair classification.

## Разбиения до эксперимента

Три циклических fold: train car-0 / validation car-1 / test car-2;
train car-1 / validation car-2 / test car-0; train car-2 / validation car-0 / test car-1.
Каждая реальная сцена оценивается один раз, все веса/проекции/covariance/пороги
строятся заново внутри fold. Игровая сцена: train car-0, validation car-1, test car-3.
Агрегация real — равновесная по сценам. Число независимых наблюдений не равно
числу пар; при трех сценах никаких confirmatory CI/p-value.

## Методы

Классический baseline: SIFT Lowe ratio .75, доля good matches относительно числа
дескрипторов reference. Отсутствие дескрипторов даёт similarity=0.
Визуальные признаки: DINOv2-small, local revision ed25f3a31f01632728cabb09d1542f84ab7b0056,
CLS, L2-normalization. Текст: текущий IndependentCaptioner qwen3.5:0.8b с пустым
scene context, затем all-MiniLM-L6-v2 revision1110a243fdf4706b3f48f1d95db1a4f5529b4d41,
L2-normalization. Fusion = concatenation [visual,text]/sqrt(2), веса фиксированы.

На каждом из visual/text/fusion сравниваются: raw cosine; PCA8 fitted on train
crops only + L2 + cosine; те же PCA8+L2 признаки с diagonal shrinkage и full
Ledoit-Wolf covariance, оцененными на симметризованных within-ID residuals
между тремя референсами и двумя кандидатами TRAIN. Ridge1e-4 добавляется к
covariance. Для diagonal shrinkage .5 к среднему variance, плюс тот же ridge.
PCA dimensions=min(8,n_train-1,feature_dimension). В full fusion остаются
межмодальные взаимодействия через общую PCA и полную матрицу в ее пространстве.
Это low-dimensional multimodal Mahalanobis, не полная768x768 covariance.

Порог отдельно для каждого метода/K/fold: только validation, minimum FPR при
TPR>=.70, далее maximum TPR и minimum threshold. Порог берётся из unique val scores;
для равных score принимается вся группа. Primary comparison: fusion vs visual
при одинаковой метрике и K; Mahalanobis vs PCA cosine на одинаковом пространстве.
Raw cosine — отдельная проверка цены/пользы PCA. Не выбирать «победителя» по test.

## Метрики и исполнение

TPR, FPR, balanced accuracy, precision, top1, confusion counts; по сценам и macro.
Отдельно стоимость captioning, визуального и текстового encoding, covariance fit,
пороговой оценки. Пары с ошибкой captioning не удаляются; блокируются с явным
status и учитываются отдельно, выводы не строятся только на успешных примерах.
Пороговые кривые test — только exploratory, не источник рабочего порога.
Seed2027; CPU; snapshots inputs/code/models, CSV/JSON scores, фигуры из этих scores.

отдельные съемки эталонов, независимые train/val/test; это не заявляется выполненным.
