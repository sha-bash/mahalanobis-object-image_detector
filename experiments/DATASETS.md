Проверено 2 октября 2026. CityFlow/VeRi/LaGOT не загружены. Для следующего
внешнего пилота загружен официальный GMOT-40 (см. ниже); пиксели вне Git.
Существующая запись: `data/search/video_test.mp4`, эталон
`data/refs/frame_000000.jpg`, `annotations/instances.json`. Есть 391 рамка
одного объекта, кадры 0–390; отрицательных меток и размеченных distractor ID нет.
Факт наличия 331 неразмеченного кадра не означает отсутствие цели.
Пользователь дал [Google Drive](https://drive.google.com/drive/folders/1SdUXDYz3GikB3pJmtE3jrBq4NESZs5c7).
Там найдено видео того же размера и три CSV: GAZEL 391 строка, 66 722 строки,
ground_truth_manual 722 строки. Владелец подтвердил tracker-assisted разметку с
последующей человеческой валидацией. Локальный GT GAZEL численно совпадает со всеми
391 строками DAY_DASIAMRPN_GAZEL. Полная GT для второго объекта доступна, но все её
метки present, без occluded. Новая независимая сцена не найдена. Автор/источник
съёмки и право распространения пока не установлены; данные остаются локальными.

## Приоритет 1 — CityFlowV2

[Официальное описание 2022](https://www.aicitychallenge.org/2022-data-and-evaluation/),
[актуальный доступ](https://www.aicitychallenge.org/ai-city-challenge-dataset-access/),
[особенности разметки](https://www.aicitychallenge.org/2022-faqs/).
Видео нескольких камер и межкамерная идентичность автомобилей позволяют брать
одно query-изображение в одной камере и искать экземпляр в другой. Использовать
доступные train/validation-аннотации, выделив собственный нетронутый test по
связанным сценам/ID. Не переиспользовать официальный test для калибровки.
Разметка неполна: исключались некоторые объекты, перекрытия, маленькие и
обрезанные машины. Поэтому отсутствие ID в GT не является надёжным absent:
нужен ручной аудит выбранных отрицательных интервалов. Не обещать полноту рамок.

Сайт сообщает, что пароль снят для перечисленных наборов, включая 2022 Track 1.
Снятие пароля не отменяет лицензию. [Опубликованное соглашение](https://www.aicitychallenge.org/wp-content/uploads/2021/01/DataLicenseAgreement_AICityChallenge_2021.pdf)
разрешает после конкурса некоммерческое академическое использование, запрещает
перераспространение данных, предусматривает ограниченные иллюстрации в научных
работах с указанием источника и закрытыми лицами/номерами. Для конкретного архива
сверить вложенную актуальную лицензию; соглашение по ссылке датировано 2021.

## Приоритет 2 — VeRi-776 для модуля идентичности

[Первичный репозиторий авторов](https://github.com/VehicleReId/VeRi/blob/master/index.md).
Более 50 тысяч изображений 776 машин, 20 камер, повторения одного экземпляра
в нескольких камерах. Подходит для positive/negative пар, обучения общей visual
ReID модели и covariance train/validation/test. Кадрированные изображения не
заменяют полное видео с выходом/возвращением: по этому набору нельзя заявлять
результат online сопровождения. Авторы выдают данные по запросу с именем и
организацией для некоммерческих целей; номерные знаки больше не предоставляются.
Запрос авторам в этой работе не отправлялся.

## Дополнение — LaGOT и LaSOT

[LaGOT Google Research](https://github.com/google-research-datasets/LaGOT) дополняет
LaSOT validation траекториями других объектов, до десяти на видео, с разметкой
10 fps. Дополнительная разметка распространяется по
[CC BY 4.0](https://github.com/google-research-datasets/LaGOT/blob/main/LICENSE).
Пиксели нужно получать отдельно у LaSOT; лицензия разметки не является лицензией
исходных видеозаписей. [Toolkit LaSOT](https://github.com/HengLan/LaSOT_Evaluation_Toolkit)
лицензирован Apache 2.0, что также не даёт автоматически прав на видео.
Подходит для same-scene crop-reference протокола и distractor/occlusion сценариев.
Межвидео тождество экземпляров не гарантируется. Нельзя выдавать его за
independent-capture ReID; licence/provenance пикселей ещё подлежат проверке.

## Практический выбор

Для тезисов быстрее собрать собственный небольшой независимый набор по PROTOCOL.md
или вручную проверить ограниченную часть CityFlowV2 с разрешённым использованием.
Для журнала добавить VeRi для модуля идентичности, CityFlow для полного видео,
LaGOT только как отдельный адаптированный протокол. Ни обычные COCO/YOLO классы,
ни естественно-языковое ранжирование готовых треков CityFlow-NL не заменяют
задачу поиска конкретного экземпляра по единственному фото.

## Выполненный следующий шаг: GMOT-40

[Официальная страница](https://spritea.github.io/GMOT40/download.html),
[репозиторий авторов и лицензия](https://github.com/Spritea/GMOT40).
В релизе v0.1 доступны JPEG-последовательности и траектории с ID экземпляров;
формат координат: нулевой индекс кадра, ID, x, y, width, height.
Лицензия авторов — CC BY-NC-SA 4.0. Архив изображений 1 498 450 771 байт,
архив траекторий 1 978 567 байт; SHA256 сохранены в `evidence/gmot40/inventory.json`.
В Git не включены исходные изображения, видео и разметка.

Использованы все четыре автомобильных ролика. При визуальной проверке `car-3`
выглядит как видеоигра: показаны отрисованные машины и окружение. Поэтому он
отделён от трёх реальных сцен в анализе. Это визуальная классификация происхождения,
а не установленный автор/движок игры. Точное межроликовое тождество машин не дано.
Авторы называют исходную задачу generic multi-object tracking; наш протокол
адаптирует идентификаторы для поиска одного экземпляра и не сравнивается с
официальным рейтингом GMOT. Один эталон из frame 0, оценка начинается с frame 1.
Отсутствие целевого ID не трактуется автоматически как физическое отсутствие.
Протокол и правило выбора зафиксированы в `GMOT40_PROTOCOL.md` до инференса.
